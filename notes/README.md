# Development record

This directory is the project's internal record: what was built, what was measured, and which
hypotheses were tested and refuted. It is written for the authors and for the paper.

**It is not documentation, and nothing user-facing should link to it.** The documentation is
`README.md`, `docs_src/` and the published site at <https://ancazugo.github.io/lczkit/>.

| Path | What it holds |
|---|---|
| `status.md` | the running record, phase by phase, with the measurement behind each decision |
| `experiments/` | one write-up per experiment: what was predicted, what was measured, what it settled |

`docs/references/` is separate and is not part of this record. Its transcribed parameter tables are
read directly by the test suite.
